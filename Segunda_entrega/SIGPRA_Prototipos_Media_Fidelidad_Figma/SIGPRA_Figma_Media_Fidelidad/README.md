# SIGPRA – Prototipo de mediana fidelidad para Figma

Este paquete contiene pantallas SVG importables directamente en Figma.

## Cómo usarlo en Figma
1. Descomprima el ZIP.
2. Abra Figma y cree un archivo nuevo.
3. Cree páginas con la misma estructura de carpetas:
   - 00 Portada
   - 01 Componentes
   - 02 Gestor de Prácticas
   - 03 Estudiante
   - 04 Docente Asesor
   - 05 Flujos
4. Arrastre los archivos `.svg` a la página correspondiente.
5. En Figma, cada SVG puede convertirse en Frame/Group y editarse.
6. Agregue conexiones en modo Prototype siguiendo los archivos de la carpeta `05_Flujos`.

Resolución base: 1440 x 900.
Estilo: mediana fidelidad, escala de grises, foco en flujo y funcionalidad.
