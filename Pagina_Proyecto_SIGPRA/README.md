# Pagina del proyecto SIGPRA

Sitio estatico para presentar el proyecto SIGPRA y enlazar sus entregables principales.

## Como abrir

Abrir `index.html` en el navegador.

## Contenido

- Resumen del proyecto.
- Enlaces a propuesta, casos de uso y prototipo Figma.
- Diagramas de arquitectura y modelo relacional.
- Documento y scripts de base de datos.
- Revision de elementos incluidos y pendientes recomendados.

## Publicacion sugerida

Para GitHub Pages, publicar esta carpeta como sitio estatico o copiar su contenido a la rama/configuracion que use GitHub Pages.
