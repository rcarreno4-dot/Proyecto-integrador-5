# SIGPRA

Sistema Integral de Gestión de Prácticas Académicas.

## Descripción

SIGPRA es un prototipo de aplicación web orientado a la gestión de prácticas académicas, con flujo de usuario para estudiantes, docentes y dirección. El proyecto incluye el diseño del sistema, la estructura de navegación y la propuesta funcional del producto.

## Objetivo del proyecto

Facilitar la administración de:

- registro e inicio de sesión
- autoinscripción del estudiante
- seguimiento de prácticas
- bitácoras y evidencias
- validación por parte de docentes
- supervisión y asignación por parte de la dirección

- `modelo_entidad_relacion.svg` — diagrama entidad-relación
- `Diagrama_De_Clases.png` — diagrama de clases
- `Diagrama_de_Componentes.png` — diagrama de componentes
- `Diagrama_de_Despliegue.png` — diagrama de despliegue
- `Diagrama_De_Dominio.png` — diagrama de dominio

## Cómo abrir el prototipo

1. Descargar el archivo `SIGPRA-Web-Prototype.make`.
2. Abrir Figma Make.
3. Importar o arrastrar el archivo al espacio de trabajo.
4. Revisar los componentes y vistas para modificar el diseño.

## Cómo visualizar el prototipo HTML

Puedes abrir directamente el archivo:

- `prototipo_mediana_fidelidad.html`

Este archivo permite revisar la maquetación visual del prototipo web en el navegador.

## Estado del proyecto

Este repositorio está orientado a la propuesta y prototipado del sistema. La estructura actual se enfoca en la parte web y de diseño del sistema, con documentación y artefactos complementarios separados en la carpeta `documentos_alternos`.
