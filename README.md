# SIGPRA

Sistema Integral de Gestion de Practicas Academicas.

## Proyecto editable en Figma Make

La exportacion completa del prototipo nuevo se encuentra en `SIGPRA-Web-Prototype.make`. Para abrirla:

1. Descarga el archivo desde este repositorio.
2. Abre Figma Make.
3. Selecciona **Archivo > Abrir/Importar** o arrastra el archivo al espacio de trabajo.
4. Entra en **Codigo** para editar `App.tsx`, los componentes y las ocho vistas.

El proyecto incluye:

- Inicio de sesion.
- Autoregistro de estudiante.
- Dashboard del estudiante.
- Bitacora y evidencias.
- Dashboard del docente.
- Validacion de bitacoras.
- Dashboard del director.
- Asignacion de practica.

Los archivos `prototipo_figma_nuevo.svg` y `prototipo_login_limpio.svg` son referencias visuales. El archivo `.make` es la exportacion editable del proyecto generado en Figma Make.
